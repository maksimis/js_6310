# Тема 12 · шаг 2 — когда перезапускаются эффекты

Кнопка «Переименовать» меняет state — срабатывает эффект без зависимостей. Кнопка «Следующий» меняет URL — эффект с `[userId]` загружает другого пользователя.

## Запуск

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # тесты (jest)
npm run lint       # eslint
npm run build      # проверка типов + сборка в dist/
```
