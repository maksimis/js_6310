Пример специфичности

Какой цвет текста применится?

Откройте DevTools (F12) → Elements → Styles и посмотрите, какие правила перекрываются.

  • p { color: gray; } — (0,0,1)
  • .text { color: blue; } — (0,1,0)
  • p.text { color: green; } — (0,1,1)
  • #title { color: red; } — (1,0,0)
  • #block p { color: orange; } — (1,0,1)
  • #block p.text { color: darkviolet; } — (1,1,1) — победит
