# Тема 10 · шаг 4 — Context API

`AuthContext` + `AuthProvider` (подключён в `main.tsx`), хук `useAuth()`, шапка `Header` показывает гостя или пользователя.

## Запуск

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # тесты (jest)
npm run lint       # eslint
npm run build      # проверка типов + сборка в dist/
```
