# Тема 12 · шаг 1 — три режима useEffect

Проект темы 10. В `UserProfile` три эффекта: после каждого рендера (заголовок вкладки), при смене `userId` (загрузка с отменой устаревшего ответа) и при монтировании (таймер с очисткой).

## Запуск

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # тесты (jest)
npm run lint       # eslint
```
