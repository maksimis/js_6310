  • Кроссплатформенность: iOS/Android
  • Те же React-принципы — компоненты, props, state
  • Нативные компоненты (не WebView)
  • Производительность близка к нативной
  • Старт: npx create-expo-app
Сборка

Как фронтенд становится «production»

  1. Исходный код — .tsx, .css, assets
  2. Транспиляция — TS → JS, современный → совместимый
  3. Бандлинг — объединение модулей
  4. Минификация — сжатие кода
  5. Выход — index.html, bundle.js, assets/

npm run build → папка dist/, особенно GitHub Pages.

Хостинг SPA и SSR

  • SPA: заливаем dist/ → GitHub Pages, Netlify, Vercel, S3
  • SSR Next.js: npm run build + npm start на Node-сервере
  • nginx — вариант раздачи статики
Безопасность — чек-лист

Перед сдачей курсовой

  • CSP — ограничение источников скриптов
  • HTTP-only cookies для токенов
  • Настроенный CORS
  • Регулярное обновление зависимостей
  • Environment variables — никаких секретов в коде

Угрозы: XSS, CSRF, Information leakage, dependency vulnerabilities.
