Что такое JavaScript

  • Высокоуровневый интерпретируемый язык
  • Не имеет отношения к Java — это не Java!
  • Даёт страницам интерактивность: формы, анимация, запросы
  • Третий «столп» веб-разработки: HTML + CSS + JS

Где работает JS

  • Браузер — формы, анимация, AJAX
  • Node.js — веб-серверы, API, БД
  • Веб-приложения — React, Vue, Angular
  • Мобильные — React Native, Ionic
  • Десктоп — Electron: VS Code, Discord, Slack
Ресурсы

Документация

  • MDN — справочник по веб и JS: developer.mozilla.org
  • Документация Node.js: nodejs.org

Окружение

  • Редактор VS Code (рекомендуется)
  • Браузер Chrome / Firefox + DevTools (F12)
  • Node.js + npm — проверка: node -v, npm -v

Совместимость функций

Прежде чем использовать новую функцию — проверьте, что она работает во всех целевых браузерах.

  • Таблицы совместимости на MDN: Chrome, Firefox, Safari, Edge
  • Курсовая и лабы сдаются в браузере, поэтому учёт поддержки важен
Первая программа

Первая программа

1.html

<script>
    // это комментарий — следующая строка выводит сообщение
    console.log("Hello, World!");
    alert("Привет, группа!");
</script>

Интерактивная демонстрация: откройте 1.html в браузере и смотрите консоль (F12 → Console).

Переменные

let и const

2.js

Управление

Условные операторы

7.js

let age = 20;

if (age >= 18) {
    console.log("Добро пожаловать!");
} else {
    console.log("Вход запрещён!");
}

// тернарный оператор
let message = (age >= 18) ? "Добро пожаловать!" : "Вход запрещён!";
console.log(message);

// else if
let time = 14;
if (time < 12)        console.log("Доброе утро!");
else if (time < 18)   console.log("Добрый день!");  // выполнится это
else                  console.log("Добрый вечер!");
Синтаксис

Шаблонные строки

8.js

const name = "Анна";
const age = 25;

// старый способ (конкатенация)
let oldWay = "Привет, " + name + "! Тебе " + age + " лет.";

// новый способ — шаблонные строки
let newWay = `Привет, ${name}! Тебе ${age} лет.`;

// можно вставлять любые выражения
let calc = `Через 5 лет тебе будет ${age + 5} лет.`;

ES6 и современный синтаксис

  • ES (ECMAScript) — стандарт языка
  • ES6 (2015) — let/const, стрелочные функции, классы, модули
  • Стандарт обновляется ежегодно — следите за новинками (tc39)
  • В курсе используем только современный синтаксис
