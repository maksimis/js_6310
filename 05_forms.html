Что такое формы

  • Контейнер для input-элементов: <form>
  • Атрибуты: action — куда отправлять, method — как
  • Сценарии: логин, регистрация, поиск, обратная связь
  • Без форм нет ни одной настоящей веб-лабы
Базовая форма

Минимальная форма

1.html

<form action="/submit" method="POST">
    <!-- Поля формы здесь -->
    <button type="submit">Отправить</button>
</form>
  • action — URL, куда уйдут данные
  • method="POST" — отправка «в теле» запроса
  • Кнопка type="submit" запускает отправку

    Отправка

    GET vs POST

    methodКогдаГде данные
    GETпоиск, фильтрыв URL: ?q=…
    POSTрегистрация, формыв теле запроса
    • Обычные формы: application/x-www-form-urlencoded
    • Файлы: enctype="multipart/form-data"
    • Без action — отправка на текущую страницу
    Обработка на JS

    submit + preventDefault + FormData

    5.html

    const form = document.getElementById('registrationForm');

form.addEventListener('submit', function (event) {
    event.preventDefault();                     // отменяем стандартную отправку
    const formData = new FormData(this);         // собираем данные формы
    const data = Object.fromEntries(formData.entries());
    console.log('Данные для отправки:', data);
});
    • preventDefault() — JS сам решает, что делать
    • FormData + entries() — данные как объект
    • Дальше — валидация и отправка через fetch
    Связка тем 3 и 4

    Форма → fetch → рендер результата

    const form = document.getElementById('registrationForm');

form.addEventListener('submit', async (event) => {
    event.preventDefault();
    const data = Object.fromEntries(new FormData(form).entries());

    if (!data.username || !data.email.includes('@')) return; // валидация

    const response = await fetch('/api/register', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(data)
    });
    const result = await response.json();

    document.getElementById('result').textContent = result.message; // в DOM!
});

    DOM (тема 3) + асинхронность (тема 4) + формы = любая реальная лаба.

    Итоги

    Формы

    • Разметка: form + label + input + select + textarea
    • Валидация: required, min/max, pattern — браузером
    • Обработка: onSubmit → preventDefault → FormData
    • Отправка: fetch(POST) → рендер ответа в DOM
    • Управляемые формы в React — та же идея (тема 8)
