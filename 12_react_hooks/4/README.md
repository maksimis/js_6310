# Тема 12 · шаг 4 — тяжёлое вычисление

`Child` считает числа Фибоначчи рекурсией прямо в рендере. Нажимайте «Count 2 +»: вычисление повторяется, хотя `counter` не изменился.

## Запуск

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # тесты (jest)
npm run lint       # eslint
npm run build      # проверка типов + сборка в dist/
```
