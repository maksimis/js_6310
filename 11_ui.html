Что это за компонент?

  • Учимся узнавать стандартные UI-компоненты по внешнему виду
  • На каждом слайде — виджет: назовите компонент
  • Ответ — на следующем слайде
  • Пригодится в lab4 (своя библиотека компонентов) и в курсовой
Вопрос 1 из 22 · Что это за компонент?

Поле «Name» с подсказкой под ним

Ответ 1

Field — поле формы

  • Field = label + control + description + сообщение об ошибке. «Required» здесь — просто плейсхолдер, а не валидация
  • В Base UI: Field

Ответ 22

Form — композиция компонентов

  • Field + Select + Number field + Slider (диапазон) + Radio group + Switch (переключатель) + Checkbox group + Button
  • В Base UI: Form
Не путать

Select · Combobox · Autocomplete · Menu

КомпонентВвод текстаРезультат
Selectнетзначение из списка
Comboboxда, фильтрует списокзначение из списка
Autocompleteда, с подсказкамилюбой текст
Menuнетвыполняется команда

Так же: Popover привязан к кнопке, Dialog модальный и поверх страницы, Toast появляется сам и исчезает сам.

Итоги квиза

Base UI — headless-библиотека

  • Все показанные виджеты — из библиотеки Base UI
  • base-ui.com/react/overview/quick-start
  • Установка: npm i @base-ui/react. На анимациях виден старый пакет @base-ui-components/react, с версии 1.0 он переименован
  • Headless: поведение и доступность готовые, стили пишете сами
  • Названия компонентов — общий словарь для lab4 и курсовой: так проще описать макет и найти готовое решение
