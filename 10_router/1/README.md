# Тема 10 · шаг 1 — первый роутер

Роутер создаётся прямо в `main.tsx`: `createBrowserRouter` + `RouterProvider`, неизвестный адрес ведёт на страницу `NotFound`.

## Запуск

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # тесты (jest)
npm run lint       # eslint
npm run build      # проверка типов + сборка в dist/
```
