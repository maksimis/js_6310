# Тема 10 · шаг 3 — динамические маршруты

Маршрут `user/:userId`: `useParams`, `useNavigate`, `useLocation`. Кнопка «Редактировать» открывает `user/:userId/edit` и передаёт `state` с адресом, откуда пришли.

## Запуск

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # тесты (jest)
npm run lint       # eslint
npm run build      # проверка типов + сборка в dist/
```
