# Тема 10 · шаг 5 — форма входа

`LoginForm`: управляемые поля, валидация, `login()` из контекста и переход на исходную страницу после входа.

## Запуск

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # тесты (jest)
npm run lint       # eslint
npm run build      # проверка типов + сборка в dist/
```
