# Тема 8 · 7_useEffect — useEffect и загрузка данных

`UserProfile` загружает пользователя с jsonplaceholder: проверка `response.ok`, сброс ошибки, флаг `ignore` против устаревших ответов, очистка заголовка вкладки.

## Запуск

```sh
npm install
npm run dev     # http://localhost:5173
npm run lint
```
