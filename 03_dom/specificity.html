Пример специфичности

Какой цвет текста применится?

Откройте DevTools (F12) → Elements → Styles и посмотрите, какие правила перекрываются.

  • p { color: gray; } — (0,0,0,1)
  • .text { color: blue; } — (0,0,1,0)
  • p.text { color: green; } — (0,0,1,1)
  • #title { color: red; } — (0,1,0,0)
  • #block p { color: orange; } — (0,1,0,1)
  • #block p.text { color: darkviolet; } — (0,1,1,1) — победит

Вложенность классов (группа C)

Ссылка с селектором .box .item .link
  • .box .item .link → 3 класса в группе C: (0,0,3,0)
  • .link → (0,0,1,0) — слабее

Сравнение идёт по группам: (0,0,3,0) > (0,0,1,0).
